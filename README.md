# Bella Exotica

**Elevate your breakfast experience with natural radiance and wellness in every spoonful.**

Bella Exotica is a **modern, responsive web application** for a premium breakfast brand, showcasing products, technology, B2B solutions, and seamless user experience. The site is built with **SEO, performance, and user engagement** in mind.

---

## 🌐 Live Demo

[https://www.bellaexotica.com](https://www.bellaexotica.com)

---

## 🚀 Features

- Fully Responsive Design — Works seamlessly on desktop, tablet, and mobile  
- SEO Optimized — Dynamic meta tags, Open Graph, Twitter cards, and JSON-LD structured data  
- Dynamic Pages — About, Products, Technology, B2B, Contact  
- Social Media Integration — OG and Twitter cards for sharing  
- Smooth Animations — Framer Motion & GSAP  
- High Performance & Accessibility — Optimized for Lighthouse scores  
- Modular Component Architecture — Clean, reusable components  

---

## 📦 Tech Stack

- **Frontend:** React.js, Tailwind CSS, Vite  
- **SEO & Head Management:** react-head, JSON-LD structured data  
- **Animations:** GSAP, Framer Motion  
- **Deployment:** Vercel (Automatic SSL, CDN, performance optimized)
